# P-40W-Warhawk-II-for-Nuclear-Option
An open-source Nuclear Option Mod, currently in the very early stages of development.

General Spec Sheet:
A modernized P-40, featuring EFI, turbosupercharging, a Merlin swap, fly-by-wire, and a new 5-blade propeller.
> Engine: 3547 HP R-R Merlin
> Price: 5.7 Million, Rank 0
 Avionics:
> FBW stolen out of a boneyard J-16 (flavor text)
> Integrated LANTIRN pod (more flavor text)
Weapons Load: 
> x5000 .50 BMG rounds divided into 10 M2s
> x300 20mm rounds, firing through prop hub
> x2 GPO-500
> x1 AAM-29 Scythe
> x19 AGR-18 Lynchpins
